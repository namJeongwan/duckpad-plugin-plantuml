# PlantUML 0.1.0

First standalone native PlantUML plugin release for Duckpad 0.10.0 (host API 1.4.0).
Requires macOS 13 or later. The universal module includes Apple Silicon and Intel.

Preview the current document or a selected file locally, zoom the diagram, open
it in a separate window, and export PNG or SVG. Runtime Settings support automatic
private Java/JAR setup and manual offline paths. The JVM is reused and exits after
ten idle minutes. Control-W closes the compact preview dock.

Install the signed plugin directory through Duckpad's Plugins Admin. Java and
PlantUML are obtained separately from their official publishers. Existing older
Duckpad releases cannot load this plugin. The package uses Ed25519 publisher signing;
the module's default Mach-O signing is ad-hoc, without Apple notarization.

Rendering supports one complete sequence diagram up to 512 KiB, a 90-second
render limit, a 512 MiB Java heap and a 32 MiB output limit. External network/includes
are disabled during rendering. Diagram types needing external Graphviz are outside
this first release. Runtime downloads require connectivity; previously installed or
manual runtime paths work offline.

Native host ABI checks and compact UI checks cover all eight translations.
Host tests additionally cover warm rendering, idle expiry, runtime changes,
cancellation, invalid inputs and child-process cleanup. Fresh native ABI and all-eight-locale UI checks passed, including Control-W routing
with English and Korean input. The host runtime checks passed with the supplied
large Korean sequence, including sandbox isolation, JVM reuse, idle expiry,
cancellation and process-group cleanup. Physical Intel hardware and macOS 13
execution have not been tested.
