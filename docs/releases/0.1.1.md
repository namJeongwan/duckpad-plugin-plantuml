# PlantUML 0.1.1

Fix installation from Duckpad's plugin catalog. Release ZIPs now contain only
the signed package files. macOS extended attributes no longer create unsigned
AppleDouble (`._`) entries that cause a signature mismatch during installation.

Requires Duckpad 0.10.0 or later (host API 1.4.0) and macOS 13 or later.
The universal module includes Apple Silicon and Intel. Java/JAR runtime paths
and existing plugin settings remain unchanged. Refresh Available Plugins in
Plugins Admin and install PlantUML 0.1.1.

Validation covers extended-attribute packaging, exact ZIP payload bytes,
refusal to replace an existing archive, publisher signature verification,
both architectures, and native plugin/UI checks. The module uses ad-hoc
Mach-O signing and Ed25519 publisher signing; it is not Apple notarized.
Physical Intel hardware and macOS 13 execution have not been tested.
